Pricing

All prices are in USD per 1 million tokens for the Standard tier.

The Input — 30-minute cache write column is the price per 1 million tokens written to the prompt cache. The 30-minute figure is how long a cached prompt prefix is retained, not a quantity of tokens. For more information, see prompt caching.

Commercial In-Region prices include a 10% fee over OpenAI rates. You do not need to add this fee.

Priority and Flex tiers are not supported for this model.
